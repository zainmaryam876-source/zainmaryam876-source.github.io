# Krishna Padmanabhan Portfolio

Static GitHub Pages portfolio. No build tools or GitHub Actions required.

## Deployment
1. Upload all files to the root of `kpadm3.github.io`.
2. In Settings → Pages, choose:
   - Deploy from a branch
   - Branch: main
   - Folder: /(root)

## Confidentiality
Employer names, product names, customer details, internal screenshots, proprietary diagrams, and confidential metrics are excluded.

## Updating case studies
Edit `assets/js/projects-data.js`. The homepage cards and reusable project page update automatically.
